# 9Router v0.5.35 Upgrade Design

## Goal

Upgrade live customized 9Router from published `0.5.30` to published `0.5.35` without losing tracked behavior, changing private routing policy, or interrupting active traffic before final promotion.

## Proven Baseline

- npm `9router@0.5.30` has `gitHead=9845a1702f7766607bd7ac3315d1f87e59e45fb5`, matching tag `v0.5.30`.
- Local source head is `45634a414208aea330bb87448540575814c22ac9` on top of that tag.
- Local source/live/DB verifier passes with zero failures and warnings.
- Published `0.5.30` bundle fails 31 tracked bundle invariants, confirming live runtime is customized.
- npm `9router@0.5.35` has `gitHead=bc252ea80298d4879dc6b3c69585af1610d2c76f`, matching tag `v0.5.35`.
- Release delta contains 27 commits and overlaps local changes in 21 files.
- A merge-tree simulation reports ten conflicts, all in GitHub, Grok, model-list, or quota paths.

## Options Considered

1. Three-way merge `local-v0.5.30-upgrade` into `v0.5.35`, then resolve ten conflicts. Recommended. It preserves every local commit and makes omissions visible.
2. Cherry-pick local commits one at a time. Rejected because 90 cumulative commits would repeatedly conflict and increase omission risk.
3. Rebuild patches manually from the ledger. Rejected because it produces clean history at the cost of reimplementing proven behavior.

## Migration Architecture

Use branch `local-v0.5.35-upgrade` rooted at signed tag `v0.5.35`. Merge the complete `local-v0.5.30-upgrade` branch with a merge commit. Resolve conflicts by keeping upstream `0.5.35` behavior first, then adding only local invariants not supplied by upstream.

Keep these boundaries:

- `grok-web`, `grok-cli`, and xAI API paths remain separate.
- GitHub Claude uses upstream native `/v1/messages`; local `/v1/responses` compatibility must feed that route, not replace it.
- Official Grok Build protocol from `0.5.35` remains base; local strict Responses codec, proxy propagation, quota details, and deterministic-error handling remain overlays.
- Private aliases, pools, credentials, best-GPT policy, and ports remain local.
- Ports `18888` and `18889` retain DC and residential roles respectively.
- Live data remains `/home/home/.9router`; candidate uses a scrubbed copy only.

## QA Boundary

Build a full standalone app before touching live files. Start candidate on `127.0.0.1:20129` with a SQLite backup whose refresh tokens are removed. Start no candidate tunnel. Run focused suites, full suite, verifier, malformed-input checks, concurrency checks, GPT/GitHub/Grok canaries, OAuth proxy checks, usage checks, console/quota checks, and approximately 1 MB Grok replay.

## Promotion And Rollback

Parameterize promotion helper for source path and expected version `0.5.35`. Require two quiet traffic snapshots, SQLite backup, same-filesystem atomic exchange, one PM2 restart, 90-second local health gate, source/live/DB verification, and raw/short tunnel health. Keep old app directory until all checks pass. Any post-swap failure exchanges old app back and restarts once.

## Upstream Work

Inventory every open PR by `ryanngit`. Rebase or recut each still-relevant public branch onto `v0.5.35`, remove code now upstream, resolve conflicts against new provider behavior, run branch-focused tests, and update existing PRs without force-pushing unless lease-safe and required. PR #2647 must use upstream Grok protocol as base while retaining only codec extensions. Private routing and deployment files stay excluded.
